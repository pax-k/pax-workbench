# ADR-006: Provider-neutral collaboration contracts precede transport

Date: 2026-07-23
Status: accepted
Task: `tasks/issues/013-define-collaboration-contracts-and-native-seams.md`

Sprint 2 collaboration policy and state live in
`src-tauri/src/collaboration.rs`. The bounded controller depends on that
provider-neutral port and invokes explicit pre-runtime and post-local-commit
hooks. Local solo mode installs a deterministic no-op port, so it performs no
network, remote claim, evidence, or handoff effect.

Concrete hosted transport must depend on these contracts; the contracts must
not depend on Tauri, an HTTP client, a provider SDK, or provider-specific
semantics. The native contract test enforces that direction. React consumes
only the sanitized projection types in `src/lib/collaboration.ts`; it never
receives capability material or provider payloads.

Capability material is a distinct native-only type: it is neither cloneable,
deserializable, nor serializable, renders only as `[REDACTED]`, and has no
general extraction API. Serializable session state uses a locally minted typed
handle; evidence and handoff references are validated nominal types; failures,
repair instructions, and missing effects are closed product-owned variants
rather than adapter-provided free-form text. Keyword scanning remains defense
in depth, not the authority boundary.

Local source hashes/Git fingerprints and remote integer `baseVersion` values
remain separate types and version domains. Future transport, envelope, claim,
and repair work extends the port without changing local Build Right authority.
